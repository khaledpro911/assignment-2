# Security Policy

## Scope

This educational repository contains short illustrative fragments, not a deployable application. Do not treat the examples as a security-reviewed production design.

## Reporting

Do not publish exploit details in an issue. Contact the repository owner privately through the GitHub security advisory mechanism when the repository is hosted. Include affected path, impact, and a minimal reproduction. No response-time guarantee is made for this coursework artifact.

## Maintainer guidance

Review direct and transitive dependencies, use trusted registries, pin and update dependencies through a risk-based process, validate framework/container configuration, and keep credentials out of source control. See `docs/05-security.md`.
